《Pentiment》中的字体设计

冰岩作坊 October 27, 2023

《pentiment》是一款由黑曜石公司开发的历史题材冒险游戏，有趣的是，该作中字体设计承担了一部分辅助叙事的功能，设计团队Lettermatic制作了五款特别的字体为游戏中角色的教育背景、职业和情绪作出诠释，有时也反映出主角对对话角色认知的变化。本文将结合Lettermatic团队在官网发布的文章，介绍字体设计亮点。原文：  https://lettermatic.com/custom/pentiment

游戏中使用的五种字体

  故事发生在16世纪的巴伐利亚，在这个充满变革与新旧对撞的时代，贵族、农民、修士与修女等不同身份背景的人们往来于塔兴这座小村庄，游戏通过不同字体的呈现反映出玩家角色——一名在本笃会修道院从事缮写工作的新人画师，眼中对话者的形象，相对应的，如果角色无意间说出一些画师意料之外的话来，ta在对话中使用的字体也会随之发生变化。

对话时，男爵的字体变为画师所使用的人文主义字体，表示此时画师自认与男爵理念相合

  • Scribe Script  文士体

      游戏中Scribe Script字体的设计受到了Cancelleresca、Batarde和Kurrent（当时的书写风格）的影响，暗示了角色良好的社会地位或教育背景。

“人类书写会产生有机的结果，充满了轻微的瑕疵，也许最重要的是：美丽的不一致……与此相反，字体（typefaces）往往每个字形只有一个版本。几百年后，当你想创造一种复制书写的字体时，它带来了一个有趣的问题。当你只记录了一个 “e “的版本，并拼出一个像 “feel”这样的词时，你就有可能让观众产生这样的想法，即使是以一种下意识的方式，即这些并不是真正的人类制造的字母。”

对传统手写体进行现代改良与再设计，复现“书写感” 将是一大难点。在设计过程中，团队共同确定了连接脚本写作风格的特征，这些特征将保留到文士体的设计当中。Scribe Script字体庞大的交替系统提供了对文字呈现方式的控制，使黑曜石的团队可以自由地使用数字工具来模拟真实的书写。例如，假设屏幕上有两行对话，而这两行对话之间恰好形成了一种 “口袋 “式的空白空间。就像一个手稿艺术家可能会在 “h ”上写上一个精心设计的升格线来填补这个负空间一样，在这种字体中，也可以通过选择各种带有精心设计的升格线的 “h ”替代品来实现。由此产生的Scribe Script字体中的一个字母都有许多变化，通过将交替的字母混合成新的组合，使用这种字体可以有成千上万种方法来呈现一个10个字母的单词。

文士体的可替换版本

  • Humanist Script  人文主义字体

游戏中的人文主义手写体是一款提供给玩家角色与游戏易读模式的字体，也是五种设计中最接近当代阅读习惯的字体，他们的灵感来源是所有衬线字体的祖先（https://zhuanlan.zhihu.com/p/25986731人文主义字体的故事 - 知乎）。同样，设计师也在数字字体中加入了每个字母的四个不同版本，以令黑曜石团队可以从同样不断变化的组合列表中进行选择。它们可以用来代表书写者的技能水平，也可以用来帮助更准确地模拟手绘文字的自然自发性。“bookkeepers”这个词包含了英语单词中最多的重复字母对，如图所示，你可以看到这个词被呈现出多种方式，每一种都很独特，就像一个人用手去书写。

人文主义字体的可替换版本

  • Monastic Script  寺院体

游戏中修士修女使用的字体，灵感源自极具宗教色彩的Blackletter、即哥特手写体。哥特手写体是一种装饰性的书写字体，出现于中世纪晚期的西欧。修道院、教堂学院以及大学需要许多教科书和书本，为降低书写材料的费用，压缩字母大小，在同样的篇幅下容纳更多的字而产生的字体。

修道院长使用的寺院体

设计团队找到了四种主要的哥特体分类：Quadrata, Semi-Quadrata, Precissa和Rotunda。在审查每种字体的样本时，他们发现了很受大家青睐的混合字体，于是开始在设计中捕捉这些细节。寺院体也有与之前的字体设计同样的轨迹，从“完美 “到 “有目的的不完美”，最终达成了「圆润的渗墨细节和不完美的笔画边缘，以更好地捕捉印刷品的结果」的核心意图。这个设计是由一个特定的 “篱笆（picket fence）”纹理形成的，艺术在于捕捉到与重复的一系列垂直线的仔细偏离，以区分一个字形和另一个字形。从叙事的角度来看，这种字母是由一个熟练使用钢笔的人慢慢地、有目的地画出来的，这是有道理的，所以设计师戴夫为字体加入了一些细节，如轻轻弯曲的垂直茎，暗示了刻字艺术家的技巧。随着人性的闪现，这些字母给人以真实的感觉。

寺院体初稿（上）与最终效果（下）的对比，后者带有墨水出血与重叠效果

  • Printer Type  印刷体

16世纪是欧洲印刷术发展的黄金时期，该时期内印刷术在欧洲迅速传播，并得到广泛应用。主角画师眼中，从事印刷工作的工匠一家使用了一种制作精巧的印刷字体，生动地再现了字形印刷的过程。

印刷体效果

“在这项研究中，我们自然而然地回到了非常早期的金属字体的幸存样本，特别是尼古拉斯·詹森（Nicolas Jenson）的作品，他在500多年前切割了一种字体，这种字体对今天的现代读者来说看起来很熟悉。我们今天所知道的同名字体 Jenson 是尼古拉斯试图将人文主义手稿写作从钢笔和墨水转移到印刷机的尝试。我们还研究了克劳德·加拉蒙（Claude Garamont，约 1530 年）和弗朗切斯科·格里福（Francesco Griffo，约 1498 年）的作品作为参考。当这些设计作为一个系列来看时，描绘了一幅当时具有开创性的纹理和风格的画面，而 Danelle 的 Printer Type 设计渴望捕捉这种基调，同时加入一些独特的精神。丹妮尔从历史样本中发现了一些细节，并将它们加以处理，仿佛暗示了玛丽·德鲁克林的偏好，比如’i’和’j’上的星形点。”

印刷体设计中小写字母“g”、大写字母“M”和星形点的历史灵感* Peasant Script  农民体

游戏中的农民及其子弟使用了这样一种更显洒脱的字体，农民手写体与前文中提到的文士手写体使用了相同的骨架，而有别于文士体的简洁、熟练、严谨，”农民文字 “则要捕捉另一种精神，即更随意、更有姿态的书写。

农民体与文士体的对照

该字体的设计师丹妮尔是一个非常熟练的字母艺术家，所以她面临的麻烦是，在这种情况下，画出 “不那么熟练 “的字母反而是有些困难的。她利用了“非优势手”的技巧，来获得她所寻找的颤抖和不完美的感觉。为了保持团队在其他设计中加入的 “手写模拟和多样性 “功能，农民字体还包括了每个字母的3个可替换版本，使《Pentiment》制作团队能够模拟书写的变化，并创造出看起来更真实的自然笔迹。它还包括一些连接词，如’ff’和’ffl’，以创造出经常出现的、容易发生碰撞的字母对之间的逼真互动。

农民字体的可替换版本

此外，游戏中还有譬如墨点、用力书写的晃动等精巧的字体动效设计，来表现对话中的情绪。在一个没有人物配音的游戏中，字体设计为玩家展现出一种特殊的交流体验，使故事更加饱满。图片来源：https://lettermatic.com/custom/pentimenthttps://youxiputao.com/article/24689#article-s2
